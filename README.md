# hxyfront-62007 植物标本馆入库

植物标本馆压制标本入库工作台（纯前端）。工作人员登记采集信息、跟踪压制与鉴定进度、
在条件齐备时办理柜位上柜，未完成鉴定或无柜位的记录不会被误当成入库。

## 功能

- **标本登记**：采集号（必填、去重）、物种（必填）、采集地点、海拔、生境、采集人、压制状态、鉴定状态。
- **入库队列**：按鉴定状态（待鉴定 / 鉴定通过 / 鉴定未通过）筛选，支持关键词搜索；卡片标注阶段（待处理 / 待上柜 / 已入库）。
- **上柜规则**：仅当**压制完成且鉴定通过**时才能分配柜位；缺少任一条件的记录保留在待处理队列并明确指出缺项。
- **柜位互斥**：柜位编号归一化比较（忽略空格与大小写），已占用柜位不能重复分配，详情中列出当前全部已占用柜位。
- **标本详情**：可编辑各字段、切换压制 / 鉴定状态、分配 / 调整 / 撤出柜位；保留全部历次变更时间线（登记、状态流转、柜位变更等）。
- **馆藏柜位记录 / 采集地点信息卡**：分别按柜位和采集地点归并展示。
- **数据存储**：全部数据保存在浏览器 localStorage（`herbarium-intake:v1`），不上传服务器；页脚可一键重置为演示数据。
